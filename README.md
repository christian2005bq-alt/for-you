# for-you — Flores animadas

Página web con una animación de flores en CSS y JavaScript.

La animación está basada en [Flower-animation de gmpsankalpa](https://github.com/gmpsankalpa/Flower-animation), distribuida bajo la licencia MIT. El código de estilos y el pequeño script se cargan desde el repositorio original; se necesita conexión a internet para esos recursos.

## Ver la página

Con GitHub Pages habilitado para la rama `main` y la carpeta raíz, visita: https://christian2005bq-alt.github.io/for-you/

## Ejecutar

Abre `index.html` en un navegador con conexión a internet.
